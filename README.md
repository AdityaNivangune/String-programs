# Java String Programs Repository
A collection of Java String manipulation programs, solved daily to strengthen core Java fundamentals, problem-solving skills, and prepare for coding interviews.

This repository contains programs ranging from basic to advanced, with clean code, comments, and structured folders for easy navigation.

## Why this repository exists
### I created this repository to:
1. Improve my Java string-handling skills
2. Practice DSA and logic building
3. Maintain a daily coding habit
4. Build a strong portfolio for Java development roles

## How to Run the Programs
1. Clone the repository:
   -> git clone https://github.com/AdityaNivangune/String-programs
2. Navigate to any folder:
   -> cd basics
3. Run a program:
   -> javac Program.java
   -> java Program
